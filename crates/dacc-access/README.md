# dacc-access

Слой доступа DACC: экспорт скомпилированного реестра в JSON (весь граф для инструментов) и XML (срез по вопросу для контекста агента).

Сериализаторы пишут строку вручную, без внешних зависимостей. Проекция берётся из констант, проверенных компилятором, а не из повторного разбора исходников.

Лицензия — [Apache-2.0](https://github.com/anishukserg/dacc/blob/master/LICENSE).
