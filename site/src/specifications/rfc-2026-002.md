# rfc-2026-002 — Слой работы: происхождение, обратимость, гейты, журнал


        Единица работы не существует без основания, а её готовность
        подтверждается доказательством, привязанным к хэшу дерева.

        Проверяемо: работа со ссылкой на несуществующее решение не
        компилируется; событие приземления без полного набора успешных
        прогонов гейтов отвергается валидатором.
    

## Input contract


        Реестр решений слоя знания; каталог гейтов продукта; каталог journal
        с событиями в TOML, по файлу на событие.
    

## Output contract


        Схемы Thrust, Slice, WorkItem, LedgerEntry, Gate; свёртка журнала
        в текущее состояние; конечный автомат переходов.
    

## Invariants

- Работа класса «реализация решения» ссылается на существующее решение — путём.
- Уборка ссылается только на замещённое решение.
- Исследование не имеет поля, объявляющего приземление кода.
- Доказательство привязано к хэшу дерева, а не коммита: коммита ещё нет в момент прогона.
- Событие журнала не изменяется после записи; состояние — свёртка.
