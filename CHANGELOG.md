# Changelog

## 0.4.0 — 2026-10-01

### Upgrade notes (breaking)

Generated by `cargo dacc upgrade 0.4.0` from the `upgrade!` registry (see
`adr-2026-044`):

- `scan_journal now takes two paths`: pass `journal.toml` and `journal/` as two
  paths in `build.rs` instead of one directory.
- `the journal is one append-only record`: no migration — `journal.toml` is an
  `[[events]]` array, `journal/` stays frozen history.
- `work start no longer writes a commit`: the ceremony is `commit` + `work
  land`; `work start` only validates.

### Anti-vacuous proof kinds

`work land` accepts `--red-before`, `--mutation-proof` and `--anti-vacuum`
(w-evidence-kinds, w-evidence-land): each kind names its subject in the landed
event, and the subject cannot be empty. A defect fix — a work with the
Divergence origin — or an irreversible change (Persistent, Irreversible) is
refused without a RedBefore proof; the refusal code is `red-before-required`.
